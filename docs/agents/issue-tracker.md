# Issue tracker: GitHub

Issues and specs for this repo live in GitHub Issues at `Y2627S1-CS3219-P5/FoC`. Use `gh` with `--repo Y2627S1-CS3219-P5/FoC` so the course template is never selected by accident.

## Conventions

- Create, read, list, comment on, label, and close issues with `gh issue` commands.
- When a skill says "publish to the issue tracker", create a GitHub issue.
- When a skill says "fetch the relevant ticket", read that GitHub issue and its comments.
- GitHub issues and PRs share numbers; resolve an ambiguous `#42` by checking its type.

## Pull requests as a triage surface

**PRs as a request surface: no.** Change this to `yes` only if external PRs should enter the triage queue.

## Wayfinding

Use one issue labelled `wayfinder:map` as the map and GitHub sub-issues as tickets. If sub-issues are unavailable, link tickets from a task list in the map. Record blockers with GitHub issue dependencies when available, or a `Blocked by: #...` line. Claim a ticket by assigning it before work; resolve it by recording the answer and closing it.
